Artifacts / Amplifiers catalog RE (2026-10-16, static, local packs only)
=========================================================================
Scripts (scratchpad/catalog_re): load.py (string-table + record reader), build_tsv.py -> artifacts.tsv,
augments.tsv, mods.tsv, stat_keys.tsv. Cached: en.pkl (English strings), b3_49.pkl (parsed 0x49 records).
TSVs contain game texts (names/effects): keep private, do not commit.

Everything lives in pack 0xA00000B3 (already local, also holds Stolen Powers).

ID convention: lists name the 0x40 class DID; the data is in the 0x49 twin (same low 24 bits),
record header "u32 did | u32 0 | u32 count | entries" (skilldata.read_record format).

3. Item type function VA 0x86E830 (DID, class):
   in collection manager (0xa1a040/0x85df40): flag ? 7 : 10;  class != [0x1B74A0C] -> 4;
   record missing -> 0; has 0x10000AB9 -> 3; 0x100009EF true -> 8 (augment); 0x100009F0 true -> 9 (mod);
   0x10000AB4 true -> 1; 0x10000AB3 true -> 2; 0x10000B38 == 1 -> 5, == 2 -> 6; else 0.
   No DID ranges / lookup table. Artifacts are not ownables (in-match), so they have no type here.
   Keys AB9/AB4/AB3/B38 do not occur in local packs (types 1,2,3,5,6 unknown: boosts/bundles/costumes?).

4. Champion base stats (partial)
   Character variant twin 0x49xxxxxx key 0x10000165 -> stat sheet 0x48 with the stat keys above
   (e.g. 0xA0000257: drone sheet 0x480014B4 = AD 45, AS 0.59, Health 1500, MoveSpeed 3).
   Gaslight Batman variant 0x49000086 (pack 0xA0000076) -> 0x10000165 = 0x4800092D (in 0xA00000B3), but that

   record/template (0x48000617 / 0x48000732, pack 0xA00000B8, not local). Unresolved.

5. String tables: tools/skills.py tail_tables/parse_table is incomplete:
   - each tail stream is chunked like the payload (0x20000 blocks, last 4 bytes trailer) starting at the stream
     start; the tail start formula overshoots (b3: real 0x1AF0C00, computed 0x1AF1000) so it misses streams;
   - a stream is ONE language holding MANY tables back to back (b3: 112 tables, 6490 strings); 4 streams =
     English, French, German, Russian (in that order); the "lang" word is not the language;
   - each UTF-16 part is padded to 4 bytes; streams can also embed non-0x2B records (images) between tables.
   load.py tail_blobs()/parse_blob()/english() handle all of this (8547 English strings from local packs).
