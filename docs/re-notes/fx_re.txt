== Server-script (0x34) node format (inferred, not interpreted by the client exe) ==
 RunScriptlet action = node type 0x10000034; operand "key | 0x00004DD4 | 2 | 0" = run KEY on SELF,
   "key | 0x00BAD844 | 1 | var" = run on the entity held in a variable. Delay = 0x10000010 followed by f32 seconds.
 Apply-skill node: "<0x48......> | var(TargetIID) | var(param)". Effects: "<0x1E......> x2 | var(duration) | var(target)".
 Variable refs: "hash | 1 | slot offset". Names table for variables at the end of each record.
 0x34000164/161 (Super Strength, caster): InitObjectPickup 0x7A2 (self), CancelPickup 0x10C3 (self),
   PickupObject 0x7A1 (self + ObjectIID), ThrowObject 0x7A0 (self + ObjectIID), _Combat_GoToLocomotion 0x2FD,
   VFX_CBT_Hit_Shared 0x223 and 0x100002F8 on a variable target, _gmCameraSystem_DamageNotice 0x3AE.
   Vars: ObjectIID, ObjectPickupScriptlet, MissileVelocity, TossDuration, BlastRadius, SkillDamage, DropObject...
 0x34000167 = THROWN-OBJECT script (in effect list 0x8E/0x30E of throwable templates, e.g. Rock 0x1D0002A7 ->
   [0x34000167, 0x34000347]; also started by 0x34000177). Everything below runs on the OBJECT (SELF) unless noted:
   start: Delay 0.3 s -> Vfx_OnThrown 0x1000087A
   fizzle (no hit within FizzleDuration): Vfx_Fade_Out 0x1000006A
   collision: Vfx_OnCollision 0x10000016; skill 0x48000295 on TargetIID with SkillDamage

     VFX_CBT_Hit_Shared 0x10000223 on TargetIID; effects 0x1E000017 + 0x1E00001A for KnockDownDuration on TargetIID;
     Vfx_OnExplode 0x10000079; destruction impulse (DestructionMagnitude / DestructionRadius at CollisionPosition);
     last: 0x1000001C on self.   Vars: CollisionPosition, ShooterIID@0x30, TargetIID@0x38, KnockDownDuration@0x40?,
     SkillDamage@0x44, FizzleDuration.
 0x340003BD (another missile object): Vfx_OnCollision -> Delay 0.2 s -> Vfx_OnExplode -> 0x10000078 (self).
